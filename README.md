# Mi Aula – Lengua Castellana

Aplicación de estudio creada con React + Vite para preparar la Prueba de Acceso a Grado Superior.

## Requisitos
- Node.js 18 o superior
- npm

## Ejecutar
```bash
npm install
npm run dev
```
Abre la dirección local que indique Vite (normalmente http://localhost:5173).

## Compilar
```bash
npm run build
npm run preview
```

## Funciones incluidas
- Temario organizado a partir de los tres PDF compartidos.
- Buscador de temas.
- Marcar temas como completados (se guarda en el navegador).
- Test de 10 preguntas con corrección y explicaciones.
- Tarjetas de memoria.
- Guía paso a paso para el comentario de texto.
- Diseño adaptable a móvil y escritorio.

## Nota sobre el contenido
Los textos de estudio se han sintetizado a partir de los documentos proporcionados. El ejemplo de Paul Auster se utiliza para mostrar las partes del texto argumentativo. Conviene contrastar cualquier ampliación futura con el material de clase.
